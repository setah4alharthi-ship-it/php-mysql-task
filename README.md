# PHP MySQL 
فكرة المشروع
سويت صفحة ويب بسيطة تدخل بيانات المستخدم مثل الاسم والعمر وتحفظها في قاعدة بيانات MySQL،
وبعدها تعرض البيانات في جدول داخل الصفحة.

 طريقة عمل الموقع
- المستخدم يكتب الاسم والعمر في الفورم
- عند الضغط على زر إرسال يتم حفظ البيانات في قاعدة البيانات
- البيانات تظهر مباشرة في جدول تحت الفورم
- يوجد زر Toggle بجانب كل مستخدم لتغيير الحالة من 0 إلى 1 أو العكس
- التغيير يصير مباشرة بدون إعادة تحميل الصفحة باستخدام JavaScript

الأدوات المستخدمة
- HTML لبناء الصفحة.
- CSS لتنسيق شكل الموقع.
- JavaScript لعمل التحديث المباشر.
- PHP لربط الموقع بقاعدة البيانات وتنفيذ العمليات.
- MySQL لحفظ البيانات.

 ملفات المشروع
- index.php : الصفحة الرئيسية وعرض البيانات.
- config.php : ملف الاتصال بقاعدة البيانات.
- insert.php : إضافة البيانات للجدول.
- toggle.php : تغيير حالة المستخدم.
- script.js : مسؤول عن التحديث بدون تحديث الصفحة.
- style.css : تنسيق الصفحة.

خطوات التشغيل
1. إنشاء قاعدة بيانات MySQL.
2. وضع بيانات الاتصال داخل ملف config.php.
3. رفع الملفات على الاستضافة.
4. فتح رابط الموقع وتجربة إضافة البيانات.
